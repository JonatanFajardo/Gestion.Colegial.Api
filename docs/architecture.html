Patrones de Diseno

Patrones implementados en la arquitectura

Repository Base

Clase generica que provee operaciones CRUD estandar via ADO.NET y stored procedures.

public class RepositoryBase
{
  Task<Answer> Read<T>(query);
  Task<Answer> Search<T>(query, param);
  Task<Answer> New(query, param);
  Task<Answer> Update(query, param);
  Task<Answer> Delete(query, param);
}

Answer Response Pattern

Objeto estandar de respuesta que envuelve todas las operaciones con tipo, mensaje y datos.

public class Answer
{
  ServiceResultType Type; // 200, 404, 500
  bool Access; // Error flag
  string Message; // User message
  dynamic Data; // Result payload
}

Service Layer

Servicios encapsulan la logica de negocio. Coordinan repositorios y transforman datos con AutoMapper.

public class AlumnoService
{
  // Repository + Mapper injected
  Task<Answer> ListAsync();
  Task<Answer> FindAsync(id);
  Task<Answer> CreateAsync(entity);
}

JWT Authentication

Autenticacion basada en tokens JWT con validacion de issuer, audience y signing key.

// JWT Configuration
Issuer: "GestionColegialAPI"
Audience: "GestionColegialUI"
Validate: Issuer, Audience,
          Lifetime, SigningKey

Dependency Injection

Todos los repositorios y servicios se registran como Scoped en Program.cs.

Soft Delete

Eliminacion logica con campo EsEliminado. Los registros nunca se borran fisicamente.

Audit Trail

Todas las entidades registran UsuarioCrea, FechaCrea, UsuarioModifica, FechaModifica.
