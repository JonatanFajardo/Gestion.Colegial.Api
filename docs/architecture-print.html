Módulos del Sistema

Académico

Alumnos, cursos, materias, notas, parciales, niveles educativos, modalidades.

Personal

Empleados, cargos, títulos académicos y asignaciones.

Financiero

Pagos, cuentas por cobrar, tarifas, conceptos de pago, reportes financieros.

Descuentos

Descuentos, moratorias, formas de pago, estados de pago.

Horarios

Horarios de alumnos, aulas, días y duraciones.

Encargados

Encargados / padres de familia y parentescos.

Dashboard

Estadísticas, alumnos por curso, notas promedio, comparación anual.

Seguridad

Usuarios, roles y autenticación JWT Bearer.

Flujo de Datos y Base de Datos

Request (Ida)

Client HTTP → Controller (Entity/DTO) → Service (Business Logic) → Repository (SqlCommand) → SQL Server (SP)

Response (Vuelta)

SQL Server (DataTable) → Repository (Mapear → Entity) → Service (AutoMapper → DTO) → Controller (Answer) → JSON

Schemas de Base de Datos

app — Académico (28 tablas) finanza — Financiero (12 tablas) seguridad — Auth (2 tablas) dbo — Stored Procedures

Convención de Stored Procedures

PR_tb{Tabla}_{Operación}
PR_tbAlumnos_List | _Find | _Detail | _Insert | _Update

API Endpoints — Base: /api/v1/

GET /ListAsync → Listar GET /FindAsync → Buscar POST /CreateAsync → Crear PUT /EditAsync → Editar PUT /RemoveAsync → Eliminar GET /DetailAsync → Detalle
